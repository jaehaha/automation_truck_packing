# 학습 가이드

학습한 모델의 출력은 실제 로봇의 모션 플래너에 그대로 들어갑니다. 아래 항목이 환경과 달라지면 학습 결과를 로봇에서 쓸 수 없습니다. 환경 규격은 [README.md](README.md)에 있습니다.

## 바꾸면 안 되는 것

이 값들은 실제 컨테이너와 로봇에서 온 것입니다. 바꿔야 한다면 먼저 로봇 쪽 담당자와 맞춰 주세요.

| 항목 | 값 | 바꾸면 생기는 문제 |
|---|---|---|
| 좌표계 | 원점 = 안쪽 벽 바닥 모서리, x = 출구 방향, 단위 mm | 로봇 좌표로 변환한 위치가 틀어집니다 |
| 공간 크기 | 820 × 480 × 480 mm | 팔이 닿지 않거나 통로를 막는 자리가 나옵니다 |
| 방향 | 흡착면(L × W)이 출구(+x)를 봄. 선택은 0°/90° 2가지 | 다른 방향은 로봇이 놓을 수 없습니다 |
| 상자 사이 틈 | 5 mm (`gap`) | 더 좁으면 플래너가 충돌로 판정합니다 |
| 진입 통로 규칙 | 상자 앞(출구 쪽)이 상자 바닥보다 낮아야 함 | 로봇이 밀어 넣을 수 없는 자리가 나옵니다 |
| 높이 한계 | 480 mm | 팔이 닿지 않습니다 |
| 상자 치수 | README의 5종 | 실물 상자와 맞지 않습니다 |
| 출력 순서 | 도착 순서와 같음 (한 스텝에 상자 하나) | 로봇은 들어온 순서대로만 집을 수 있습니다 |

## 지켜야 할 사용 방법

- **행동은 항상 `action_mask` 안에서 고릅니다.** 마스크가 위 규칙을 모두 검사합니다. 마스크 없이 학습하면 놓을 수 없는 자리를 고르는 정책이 됩니다.
- **자리 검사 함수(`_feasible`)와 안정성 검사(`_settle`)는 고치지 않습니다.** 규칙을 완화하면 학습은 쉬워지지만 결과가 로봇에서 실패합니다.
- **결과는 `export()` 형식 그대로 넘깁니다.** `center`(상자 중심, mm)와 `dims_xyz`(놓은 뒤 x·y·z 치수)가 위치와 방향의 전부입니다. 격자 칸 번호나 행동 번호로 넘기지 않습니다.
- **평가는 `physics=True`로 합니다.** 학습 속도를 위해 `physics=False`로 돌려도 되지만, 최종 평가는 물리 검사를 켠 상태여야 합니다.

## 자유롭게 바꿔도 되는 것

| 항목 | 방법 |
|---|---|
| 보상 | `Config`의 `w_util`, `w_block`, `w_fail` 또는 래퍼로 재정의 |
| 관측 | 래퍼로 가공 (높이 지도 변형, 미리 보는 상자 수 `lookahead` 등) |
| 에피소드 분포 | `shares`(종류별 비율), `stops`, `per_stop`, `order` |
| 정해진 입력으로 평가 | `env.reset(options={"job": [(지점, 종류), ...]})` |
| 학습 알고리즘, 네트워크 | 제한 없음 |

- **격자(`grid`)**를 5 mm로 줄이면 더 촘촘하게 놓을 수 있습니다. 행동 수가 7,872개에서 31,488개로 늘어납니다. 출력 좌표는 여전히 mm이므로 로봇 쪽에는 영향이 없습니다.
- **받침 비율(`support_min`)**은 올리는 것만 괜찮습니다. 낮추면 넘어지는 배치가 늘어납니다.

## 평가 기준

기준 정책(`pack_env.greedy`)과 같은 seed로 비교합니다.

| 지표 | 기준 정책 (seed 0 ~ 3) | 목표 |
|---|---|---|
| 하차 순서 위반 | 0건 | 0건 유지 |
| 부피 사용률 | 41 ~ 59 % | 더 높게 |
| 놓지 못한 상자 | 0 ~ 1개 | 0개 |

하차 순서 위반이 생기면 실제로는 상자를 꺼낼 때 앞의 상자를 다시 옮겨야 합니다. 사용률보다 위반 0건이 우선입니다.

## 넘겨주기 전 확인

```bash
uv run python pack_env.py --check              # 환경을 고쳤다면 규격 검사
uv run python pack_env.py --save-json out.json # 결과 형식 예시
```

- 모든 상자가 마스크 안의 행동으로 놓였는지
- `info["reason"]`에 `unstable`, `invalid_action`이 없는지
- 결과가 `export()` 형식(`id`, `type`, `stop`, `center`, `dims_xyz`)인지
