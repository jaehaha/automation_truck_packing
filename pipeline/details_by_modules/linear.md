# 리니어 액추에이터 연결에 필요한 정보

`motion.json`의 경유점(레일 위치 + 관절 6개 + 흡착)을 실물로 실행하려면 아래 값을 알아야 한다.
아두이노 스케치(.ino)가 있으면 1~3번은 거기서 대부분 확인할 수 있다.

## 1. PC ↔ 아두이노 통신

- [ ] 연결 방식과 포트 이름 (예: USB 시리얼, `/dev/ttyACM0`)
- [ ] 통신 속도 (baud)
- [ ] 이동 명령 형식 (예: `G 350\n` → 350 mm 로 이동)
- [ ] 응답 형식 (이동 완료, 현재 위치를 돌려주는지)

## 2. 위치 지정 방식

- [ ] 모터 종류와 드라이버 (스테퍼 / 서보 / DC + 엔코더)
- [ ] 명령 단위: 절대 위치(mm 또는 스텝)인지, 상대 이동량·속도인지
- [ ] 스텝 단위라면 1 mm 당 스텝 수 (리드 길이, 마이크로스텝)
- [ ] 위치 피드백: 엔코더가 있는지, 스텝 수로만 추정하는지

## 3. 원점과 한계

- [ ] 원점 잡기(호밍) 방법, 리밋 스위치 유무
- [ ] 레일 0 일 때 팔 베이스 중심이 프레임 입구 쪽 끝에서 몇 mm 인지 (모델 가정: 200 mm)
- [ ] 실제 이동 가능 거리 (모델 가정: 1000 mm)
- [ ] 값이 커질 때 움직이는 방향 (컨테이너 안쪽인지)

## 4. 움직임 특성

- [ ] 안전하게 쓸 수 있는 최대 속도와 가속도
- [ ] 이동 중에 새 목표를 보내면 바로 따라가는지, 한 이동이 끝나야 다음 명령을 받는지
- [ ] 위치 반복 정밀도 (같은 위치로 여러 번 보냈을 때 몇 mm 안에 들어오는지)

"이동 중 목표 갱신"이 가장 중요하다. 경로에는 레일과 관절이 동시에 움직이는 구간(상자를 들어 올리며 돌리는 구간)이 있어서,
레일이 "목표 하나 보내고 끝날 때까지 대기" 방식이면 팔과 타이밍을 맞추는 방법을 따로 정해야 한다.
밀어 넣기는 레일만으로 40 mm 전진하므로 반복 정밀도도 놓는 위치에 그대로 반영된다.

## 5. 흡착 솔레노이드

- [ ] 레일과 같은 아두이노에서 제어하는지, 별도 보드인지
- [ ] 켜고 끄는 명령
- [ ] 상자가 붙었는지 확인할 수 있는지 (진공 센서 등)
