# ArUco 로 상자 위치를 재서 집는 방법과 통합 프로그램 구성

경로 자체는 `heuristic_motion.py`가 미리 만든 `motion.json`을 쓴다. 카메라는 그 경로를 새로 만드는 게 아니라
**"상자가 계획 위치에서 얼마나 어긋났는지 (dx, dy, yaw)"** 만 재서 집는 부분을 고치는 데 쓴다.
(`Templater.adjust_pick(waypoints, dx, dy, yaw)` 가 그 값을 받아 집기 주변 경유점만 다시 푼다.)

## 1. 카메라 두 대의 역할

| | 전체뷰 카메라 (고정) | 손목 카메라 (팔에 부착) |
|---|---|---|
| 정밀도 | 거침 (수 mm ~ 1 cm) | 정밀 (1 mm 안팎 목표) |
| 하는 일 | 투입 칸에 상자가 왔는지, 어떤 상자인지(마커 id), 대략 제자리인지 확인. 놓은 뒤 결과 확인 | 집기 직전에 가까이서 마커를 보고 dx, dy, yaw 를 잰다 |
| 값이 쓰이는 곳 | 시작 신호, 잘못된 상자·크게 벗어난 상자 거르기 | `adjust_pick` 입력 |

## 2. 미리 해 둘 보정 (한 번씩)

1. **카메라 내부 보정**: 두 카메라 각각 체커보드(또는 ChArUco)로 초점거리·왜곡을 구한다.
2. **전체뷰 카메라 위치**: 프레임의 알려진 자리에 기준 마커 3~4개를 붙여 두고, 그 마커로 카메라 → 리그 좌표 변환을 구한다.
   기준 마커를 계속 붙여 두면 카메라가 조금 틀어져도 매번 다시 맞출 수 있다.
3. **손목 카메라 위치 (hand-eye)**: 카메라가 플랜지(관절 6) 기준 어디에 달렸는지 구한다.
   고정된 마커 하나를 여러 팔 자세에서 찍어 `cv2.calibrateHandEye` 로 푼다.
4. **흡착 컵 끝 위치**: 툴 길이(모델 가정 80 mm)를 실측한다.

## 3. 상자 하나를 집는 순서

1. 사람이 투입 칸에 상자를 놓는다. 전체뷰 카메라가 마커 id 로 **상자 종류와 순서(`feed_order`)가 맞는지**, 칸 안에 있는지 본다.
   틀리면 멈추고 알린다.
2. 팔이 `ready` → `approach` 첫 경유점(촬영 자세)까지 간다. 이 자세는 툴이 약 22° 기운 채 상자 위에 있어서 손목 카메라가 윗면을 본다.
3. 손목 카메라로 마커를 재서 dx, dy, yaw 를 구한다 (여러 장 평균).
4. 값이 허용 범위(예: ±10 mm, ±10°)를 넘으면 집지 않고 사람에게 다시 놓게 한다.
5. `adjust_pick` 으로 고친 경유점대로 내려가 흡착 → 나머지는 `motion.json` 그대로.
6. 놓은 뒤 `ready` 로 돌아오면 전체뷰 카메라로 놓인 결과를 확인하고(선택), 다음 상자 투입을 알린다.

### 측정할 때 지킬 것

- **높이는 재지 않는다.** 상자 종류를 알면 윗면 높이는 정해져 있다. 마커 중심으로 가는 시선과 그 높이의 평면이 만나는 점을 쓰면
  마커 자세 추정(PnP)의 깊이 오차를 피할 수 있다.
- **툴 기준으로 잰다.** "마커가 컵 끝에서 얼마나 떨어졌나"를 툴 좌표로 구해 보정하면 레일 위치 오차가 상쇄된다.
- **마커 위치를 정해 둔다.** 윗면 중앙에 컵이 닿으므로 마커는 중앙에서 일정하게 비켜 붙이고(예: 한쪽 모서리),
  상자 종류별로 "마커 중심 → 윗면 중심" 오프셋을 표로 둔다. 가장 작은 윗면은 80 × 80 mm 다.
- **가까운 거리 초점.** 촬영 자세에서 카메라와 윗면 사이가 10 cm 안팎이므로 그 거리에서 초점이 맞는 카메라여야 한다.

## 4. 통합 프로그램 구성

장치마다 모듈을 나누고, 실행기는 `motion.json` 을 한 이동씩 따라가는 상태 기계로 만든다.

| 모듈 | 내용 |
|---|---|
| `arm.py` | Piper SDK. 관절 목표를 보간해 보내기 (`piper_keyboard.py` 의 방식 그대로) |
| `rail.py` | 아두이노 시리얼로 레일 위치 명령 / 현재 위치 읽기 (`linear.md` 참고) |
| `suction.py` | 솔레노이드 켬 / 끔 (같은 아두이노면 `rail.py` 와 합친다) |
| `vision.py` | 두 카메라 보정값 로드, 마커 검출, (dx, dy, yaw) 계산 |
| `executor.py` | `motion.json` 로드 → 이동마다 3절 순서 실행. `heuristic_motion.Templater` 로 `adjust_pick` 호출 |

실행기 상태: `대기(상자 투입) → 확인(전체뷰) → 촬영 자세 → 측정(손목) → 집기 → 운반 → 넣기 → 복귀 → 대기`.
어느 단계든 실패하면 그 자리에서 멈추고(팔은 자세 유지) 이유를 표시한다.

### 만드는 순서 (하나씩 확인하며)

1. `arm.py`: `motion.json` 의 한 이동을 **빈손, 레일 없이, 느리게** 따라가 보기
2. `rail.py` + 팔 동시 이동 (레일과 관절이 같이 움직이는 flip 구간의 타이밍 맞추기)
3. `suction.py`: 고정 위치에서 집고 놓기
4. `vision.py`: 보정 → 손목 카메라로 잰 값이 자로 잰 값과 맞는지 확인
5. `executor.py`: 측정 → `adjust_pick` → 집기까지 연결, 그다음 전체 순서

## 5. 먼저 정해야 할 것

- [ ] 마커 사전과 크기 (예: `DICT_4X4_50`, 한 변 30 mm), 마커 id ↔ 상자 id(종류) 대응
- [ ] 마커를 윗면 어디에 붙일지 (컵과 겹치지 않는 자리)
- [ ] 카메라 기종과 해상도, 손목 카메라 장착 위치 (컵·상자에 가리지 않고 팔 동작에 걸리지 않는 곳)
- [ ] 전체뷰 카메라 설치 위치 (투입 칸과 적재 공간이 함께 보이는 곳)
- [ ] 허용 오차 범위 (넘으면 다시 놓게 할 기준)
- [ ] 손목 카메라 무게·부피가 모델에 없으므로, 달고 나면 충돌 검사 모델(`rig/model.py`)에 추가할지
