# 흡착 그리퍼(솔레노이드 밸브) 통합에 필요한 정보와 구현 방안

지금 구조: 흡착 컵으로 가는 우레탄 호스 중간에 솔레노이드 밸브를 달아,
**밸브를 열면 공기가 밖으로 새서 흡착 꺼짐 / 밸브를 막으면 흡착 켜짐**. 밸브는 아두이노가 제어한다.

`motion.json` 의 경유점마다 `suction` 값(1 켬, 0 끔)이 있고, 실행기는 그 값이 바뀌는 점에서 밸브를 바꾼다.
한 이동에 두 번이다: `pick` 에서 켜고, `insert` 끝에서 끈다.

## 1. 알아야 할 것

### 배선과 신호
- [ ] 밸브를 구동하는 아두이노 핀 번호와 구동 회로 (릴레이 / MOSFET, 역기전력 다이오드 유무)
- [ ] 핀이 HIGH 일 때 흡착이 켜지는지 꺼지는지
- [ ] 레일과 같은 아두이노인지, 별도 보드인지 (같다면 시리얼 포트 하나를 함께 쓴다)

### 전원이 끊겼을 때의 상태 (가장 중요)
- [ ] 밸브에 전기가 안 들어갈 때 열려 있는지(흡착 꺼짐) 닫혀 있는지(흡착 켜짐)
- [ ] 진공 펌프는 항상 켜 두는지, 따로 제어하는지

상자를 든 채로 프로그램이 죽거나 아두이노가 리셋되면 밸브는 "전기 없음" 상태로 돌아간다.
그때 흡착이 꺼지는 구조라면 상자가 떨어진다. 어느 쪽인지 알아야 정지·종료 처리를 정할 수 있다.

### 시간
- [ ] 켠 뒤 상자가 확실히 붙을 때까지 걸리는 시간
- [ ] 끈 뒤 상자가 확실히 떨어질 때까지 걸리는 시간 (컵이 붙어서 안 떨어지는 경우가 있는지)

### 잡는 힘
- [ ] 가장 무거운 상자 무게
- [ ] **옆으로 든 상태**에서 버티는지: 운반할 때 툴이 앞(+x)을 보므로 상자 무게가 컵을 옆으로 미는 방향으로 걸린다
- [ ] 밀어 넣을 때 버티는지: 마지막 40 mm 는 아래 상자 위를 끌면서 들어간다
- [ ] 밸브를 열었을 때 펌프가 켜져 있어도 완전히 떨어지는지 (배출 구멍이 작으면 약하게 계속 붙는다)

### 확인 수단
- [ ] 상자가 붙었는지 알 수 있는 센서가 있는지 (진공 압력 센서 등). 없으면 시간 지연만으로 진행해야 한다

## 2. 구현 방안

### 아두이노 쪽
시리얼로 한 줄 명령을 받고 한 줄로 답한다. 레일과 같은 보드면 같은 규칙에 명령만 더한다.

| 명령 | 동작 | 응답 |
|---|---|---|
| `V1` | 흡착 켬 (밸브 막음) | `OK V1` |
| `V0` | 흡착 끔 (밸브 엶) | `OK V0` |
| `V?` | 현재 상태 (센서가 있으면 압력도) | `V1 P=-45` |

- 켜질 때(`setup`)의 초기 상태를 명시적으로 정한다.
- 레일 이동처럼 오래 걸리는 동작 중에도 `V` 명령은 바로 처리되게 한다 (`delay` 로 막지 않기).

### PC 쪽 (`suction.py`)
```python
class Suction:
    def on(self):   # V1 보내고 응답 확인 -> 붙을 때까지 대기 (센서 있으면 압력 확인, 없으면 정한 시간)
    def off(self):  # V0 보내고 응답 확인 -> 떨어질 때까지 대기
    def holding(self) -> bool | None:   # 센서가 있을 때만. 없으면 None
```
레일과 포트를 같이 쓰면 포트를 여는 객체는 하나만 두고 `Rail` 과 `Suction` 이 그것을 함께 쓴다.

### 실행기에서의 사용
- `suction` 이 바뀌는 경유점에서는 **팔과 레일을 완전히 멈춘 뒤** 밸브를 바꾸고, 대기 시간이 지난 다음 출발한다.
- `pick`: 컵이 닿은 뒤 `on()`. 센서가 있으면 붙지 않았을 때 들어 올리지 않고 멈춘다.
- `insert` 끝: `off()` 후 대기 → 그다음 `retreat`. 덜 떨어진 채 빼면 상자가 끌려 나온다.
- 운반 중: 센서가 있으면 주기적으로 `holding()` 을 보고, 놓쳤으면 그 자리에서 멈춘다.
- 정지·오류·`Ctrl+C`: 상자를 들고 있으면 흡착을 **끄지 않고** 팔만 멈춘다. 끄는 것은 사람이 확인한 뒤 따로 한다.

## 3. 확인 순서

1. 팔 없이 손으로 상자를 대고 `V1` / `V0` 로 붙고 떨어지는 시간 재기
2. 가장 무거운 상자를 붙여 컵을 옆으로 눕혀 보기 (운반 자세), 살짝 밀어 보기 (넣기)
3. 상자를 든 채 아두이노 전원·USB 를 뽑아 어떻게 되는지 보기
4. 팔로 고정 위치에서 집기 → 들기 → 놓기 반복해 대기 시간 확정
